    🔄 Recent Searches (Queue)

    Member 2
    FIFO • O(1) Sliding Buffer
    Maintains a bounded sliding window of the last 5 queries using a Queue. When a 6th search is enqueued at the tail, the oldest entry at the head is evicted in O(1) time.

    🌲 Trie (Prefix Tree)

    Member 1
    Prefix Autocomplete • O(L + K)
    Stores vocabulary tokens across a n-ary character tree. Finding words matching prefix of length L takes O(L) to reach the prefix node, plus O(K) to collect K candidate completions.

    ⚖️ PriorityQueue (Max-Heap)

    Member 2
    Max-Heap • O(K log N)
    Documents matching a search are placed in a Binary Max-Heap. The document with highest keyword frequency sits at the root. Ties in score are broken alphabetically by file name.
    LATEST QUERY HEAP EXTRACTION TRACE: No Query

    📑 Inverted Index (Postings List)

    Member 1
    HashMap • O(1) Lookup
    Maps every unique word token to a postings list of documents where it occurs, alongside term frequencies. Enables instantaneous O(1) average-case retrieval for multi-word queries.
